# Design Partner Outreach

Materials for recruiting **3–5 private beta partners** for Dedalus Converger.

| File | Use |
|------|-----|
| [design-partner-email.md](design-partner-email.md) | Copy-paste email templates (Proxmox, DFIR, cloud, LinkedIn) |
| [partner-directory.md](partner-directory.md) | Segments, channels, starter targets, outreach tracker |
| [partner-tracker.csv](partner-tracker.csv) | Spreadsheet tracker — import to Excel/Sheets |
| [partner-prospects.md](partner-prospects.md) | **15 named prospects** with emails, hooks, ready-to-send drafts |

**Send from:** licensing@dedalo101.com (or your founder inbox)  
**Product site:** https://dedalus-converger.pages.dev  
**Onboarding after reply:** [PRIVATE_COLLABORATION.md](../PRIVATE_COLLABORATION.md)

## Quick workflow

1. Pick 10–15 names from [partner-directory.md](partner-directory.md)
2. Choose the matching template in [design-partner-email.md](design-partner-email.md)
3. Personalize one line (their stack, a post they wrote, a tool they use)
4. Log the send in [partner-tracker.csv](partner-tracker.csv)
5. Follow up once after 5–7 days if no reply
